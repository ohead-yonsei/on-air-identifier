# ON-AIR — 중계 화면만 보고 선두권 말 번호 알아내기

경마 중계 AI가 지어내는 말(환각)을 줄이는 벤치마크 프로젝트 **ON-AIR**의 한 부분입니다. 가설은 "어려운 순간에 말을 틀리게 부르는 대신 확정 정보로 메우면 환각이 줄어든다"이고, 이 저장소는 그 확정 정보 가운데 **"지금 선두권에 몇 번 말이 있는가"를 화면에서 알아내는 식별기**를 만들고 시험한 기록입니다.

**정리 페이지: https://ohead-yonsei.github.io/on-air-identifier/**

## 한눈에

기수 모자색은 말 번호마다 정해져 있습니다(1 흰색, 2 노랑, 3 빨강, 4 검정, 5 파랑, 6 초록, 7 갈색, 8 분홍, 9 보라, 10 하늘, 11번부터 하늘색 줄무늬). 식별기는 화면에서 기수를 찾고, 모자색으로 번호를 읽고, 앞선 말을 골라 "선두권에 N번"이라고 말합니다.

| 무엇 | 결과 | 어디서 쟀나 |
|---|---|---|
| 말한 번호가 실제 상위 3두였던 비율 | 94.3% (1459개 중 1376개) | 처음 보는 경마일 6일, 60개 경주 |
| 맞는 번호를 하나 이상 말한 시점 | 89.0% (874개 중 778개). 날에 따라 82~95% | 같은 6일 |
| "선두는 N번" | 87.5% (344번 중 301번). 10월 5일·3일에서는 94.0%였음 | 9월 19일~8월 30일의 4일, 선두 기준값 0.5 |
| "a번이 b번보다 앞" | 91.4% (336번 중 307번). 10월 5일·3일에서는 93.0% | 같은 4일 |
| Qwen 없이 분류기만 쓴 빠른 구성 | A 94.3%, B 87.6%. 시점당 8.3초 → 2.3초 | 같은 4일 |
| 틀린 번호가 들어간 중계 문장 | 화면만 본 모델 138개 → 식별기를 쓴 중계 7개 (140개 시점) | 2026-11-15, 11개 경주 |

- 위 표의 숫자는 **방송 순위 띠가 화면에 있는 구간**의 것입니다. 띠가 없는 구간(출발 직후, 마지막 30초쯤)은 공식 경주 기록을 정답으로 따로 쟀습니다: 띠 없이 경주 전체를 돌리면 A 92.6%, B 89.9%(안 쓴 6일, 43개 경주). 결승 3초 전까지는 띠 구간과 같은 수준이고, 약한 곳은 출발 직후와 결승 순간입니다([finish2/RESULT_KO.md](experiments/onair_labelset_20261117/finish2/RESULT_KO.md)).
- 서울 경마장, 한국마사회 국제 채널(KRBC International) 화면에서만 만들고 확인했습니다.
- 자세한 한계는 정리 페이지와 각 실험의 `RESULT_KO.md`에 있습니다.

## 실행

GPU 서버에서 실행합니다(RTX 3090에서 확인). Python 패키지(PyTorch, torchvision, OpenCV, scikit-learn)가 필요하고, 기본 구성(v9)은 번호를 읽는 데 언어 모델을 쓰지 않습니다. 순위 띠는 번호를 정하는 데 쓰지 않습니다. 띠가 화면에 있는지 함께 적는 확인(`--strip-check`, 채점용, 2026-11-19부터 기본으로 꺼짐)과 `--v8`만 로컬 Ollama의 Qwen 9B를 씁니다. 유료 API는 쓰지 않습니다.

