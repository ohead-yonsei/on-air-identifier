# ON-AIR 초안 벤치마크 v0 — "지금 선두권은 몇 번인가"

2026-11-18 초안. 경마 중계 AI가 **화면에서 알 수 없는 것을 지어내는 정도**를 재는 첫 묶음이다. 순위 띠를 가린 경주 화면을 보여 주고 중계 한 문장을 말하게 한 뒤, 그 문장에 나온 말 번호가 그 순간의 실제 순위와 맞는지 센다.

정답은 방송사가 화면 아래에 띄우는 **순위 띠**(1~5위 번호)다. 그래서 이 초안은 띠가 화면에 있는 구간(대략 출발 17초 뒤부터 결승 30초 전까지)만 다룬다.

## 재려는 흐름

1. AI가 띠 없이 화면만 보고 중계한다.
2. 순위를 확실히 알 때는 순위를 말한다.
3. 확실하지 않을 때는 확정 정보(경주 번호, 거리, 경과 시간)로 말한다.

좋은 시스템은 **틀린 번호를 말하지 않으면서, 번호를 충분히 많이 말한다.** 둘을 함께 봐야 한다. 번호를 아예 말하지 않으면 틀릴 일이 없고, 아무 번호나 셋씩 말하면 하나쯤은 맞기 때문이다(아래 기준선 표의 처음 두 줄).

## 문항

| | |
|---|---|
| 한 문항 | 한 경주의 한 순간 (3초 간격, 띠가 화면에 있던 순간) |
| 규모 | 서울 열하루, 109개 경주, 1,606문항 |
| 시험용 (test) | 6일, 60개 경주, 874문항 — 우리 식별기를 만들 때 한 번도 쓰지 않은 날 |
| 개발용 (dev) | 5일, 49개 경주, 732문항 — 식별기의 학습과 선택에 쓰인 날. 프롬프트를 다듬는 데 쓴다 |
| 입력 | 그림 3장(1초 전, 0.5초 전, 그 순간. 1920×1080, 띠는 회색으로 가림) + 경주 정보(경주 번호, 거리, 출전 번호) + 출발 뒤 경과 시간 + 모자색 규칙 |
| 출력 | 한국어 중계 한 문장. 말은 이름 대신 "N번"으로 부른다 |
| 정답 | 그 순간 띠에 적힌 1~5위 번호 |

모자색 규칙(한국 경마의 공통 규칙): 1번 흰색, 2번 노란색, 3번 빨간색, 4번 검정, 5번 파란색, 6번 초록색, 7번 갈색, 8번 분홍색, 9번 보라색, 10번 하늘색, 11번부터는 하늘색 바탕에 줄무늬.

## 채점 (`score.py`)

문장에서 "N번"을 모두 찾아, 그 번호를 "선두권에 있다"는 주장으로 본다. "선두는 N번", "N번이 선두", "N번이 앞장" 같은 표현은 선두 주장으로 따로 센다.

| 숫자 | 뜻 | 좋은 방향 |
|---|---|---|
| **틀린 문장 비율** | 띠의 1~3위가 아닌 번호가 하나라도 든 문장의 비율 | 낮을수록 |
| **A (번호 정확도)** | 말한 번호 중 띠의 1~3위인 것의 비율 | 높을수록 |
| **B (말한 양)** | 맞는 번호를 하나 이상 말한 문항의 비율 | 높을수록 |
| 선두 주장 | 선두라고 한 번호가 띠의 1위인 비율, 그리고 선두를 말한 문항의 비율 | 높을수록 |
| 틀린 번호의 종류 | 띠의 4~5위(아깝게 틀림) / 그 경주에 없는 번호(완전히 지어냄) / 그 밖 | — |

범위는 경주 단위로 다시 뽑아(2000번) 95% 구간으로 단다. 3초 간격의 문항은 서로 닮았기 때문이다.

괄호 안의 범위는 경주 단위로 다시 뽑은 95% 구간이다. 문항 수가 874보다 적은 줄은 아직 다 돌리지 못해 무작위로 뽑힌 일부만 채점한 것이다.

- **화면만 본 모델**은 로컬에서 돌린 작은 모델(Qwen 3.5 9B) 하나다. 큰 모델이나 유료 모델은 돌리지 않았다.
- **우리 흐름**은 식별기(빠른 구성 F2: 기수 검출 → 모자색 분류 → 앞선 말 고르기 → 여러 장 투표, 언어 모델 없음)가 낸 번호를 정해진 틀의 문장에 넣은 것이다. 식별기가 아무 번호도 확정하지 못한 문항에서는 확정 정보만 말한다. 문장을 다듬는 언어 모델은 쓰지 않았다.

## 쓰는 법

```bash
python3 benchmark/v0/build_items.py                          # 문항·정답·경주 정보 다시 만들기 (실험 기록에서)
python make_inputs.py --exp <실험 폴더> --split test          # 입력 그림 만들기 (영상이 있는 곳에서, opencv 필요)
python3 benchmark/v0/score.py 내_출력.jsonl --split test      # 채점
```

출력 파일은 한 줄에 한 문항이다: `{"id": "20260919_R01_t029", "text": "선두는 3번, 선두권에 5번도 있습니다."}`. 한국어가 아닌 출력을 채점하려면 `"numbers": [3, 5]`, `"leader": 3`을 함께 적으면 문장 대신 그 값을 쓴다.

## 파일

| 파일 | 내용 |
|---|---|
| `items.jsonl` | 문항: 경주, 영상 시각, 그림 3장의 시각, 경과 시간, 시험용/개발용 |
| `answers.jsonl` | 정답: 문항별 띠의 1~5위 번호 |
| `races.json` | 경주 정보: 날짜, 경주 번호, 거리, 출전 번호, 영상(유튜브 ID와 제목), 띠 위치 |
| `build_items.py`, `make_inputs.py`, `score.py` | 만들기, 입력 그림 뽑기, 채점 |
| `baseline_trivial.py`, `baseline_vlm.py`, `baseline_ours.py` | 기준선 세 종류 |
| `baselines/*.jsonl`, `*.score.json` | 기준선의 출력과 점수 |
| `ident/F2_*.json` | 우리 흐름이 쓴 식별기 출력 (날마다) |

입력 그림과 영상은 이 폴더에 넣지 않았다. 문항은 유튜브 영상 ID와 시각으로 가리킨다.

## 한계 (초안이라 큰 것들)

- **띠가 있는 구간만 다룬다.** 출발 직후 17초쯤과 마지막 30초쯤은 띠가 없어 빠져 있다. 결승 순간과 우승마가 여기에 들어 있지 않다. 공식 경주 기록으로 이 구간을 채점하는 방법을 따로 만들고 있다(`experiments/onair_labelset_20261117/finish2/`).
- **정답을 모델이 읽었다.** 띠의 번호는 로컬 모델이 방송 화면에서 읽었다. Claude가 직접 읽은 38장과 대조하면 37장이 같았다. 문항별 검수는 하지 않았다. 띠는 실제 순위보다 조금 늦게 바뀔 수 있다.
- **번호만 채점한다.** 추월, 거리 차이, 말 상태 같은 다른 주장은 보지 않는다. "N번"이라는 글자를 찾는 규칙이라, 번호를 다르게 쓰는 문장은 놓친다.
- **한 문장씩 따로 본다.** 이어지는 중계의 흐름(같은 말 되풀이, 말투, 타이밍)은 재지 않는다.
- **확정 정보 문장이 사실인지는 채점하지 않는다.**
- **우리 흐름의 문장은 틀에 넣은 것이다.** 자연스러운 중계 문장이 아니다. 언어 모델이 문장을 다듬으면 번호가 바뀔 수 있는데, 그 단계는 여기서 재지 않았다.
- **한 경마장, 한 방송사, 낮 경주 위주다.** 11번 이상은 모자색이 같아 서로 구분할 수 없다.
- **영상 공개 범위가 정해지지 않았다.** 지금은 영상 ID와 시각만 싣는다.
