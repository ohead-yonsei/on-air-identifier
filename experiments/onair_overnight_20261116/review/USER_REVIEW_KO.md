# 오전 검수 목록

새 라벨은 자동 승인하지 않았다. 아래 세 가지를 우선 확인하면 다음 실험의 기준을 만들 수 있다. 지금까지의 계산은 사용자 확인 전의 육안 초안과의 일치 수다.

1. **선두와 모자:** 31·34·37·40·42·48·52·58초의 선두가 모두 보라색 9번인지 확인한다. 판단이 어려운 시점은 ‘미확인’으로 남긴다.
2. **코끝–기수 대응:** 녹색 선이 같은 말의 코끝과 기수 모자를 잇는지 확인한다. 코끝의 정확한 위치와 대응 관계는 별도 항목이다. 가려진 40초·52초의 5번 코끝은 이미 평가에서 제외했다.
3. **정면·코너의 순위 기준:** 37·48·52초에서 자동 이동 방향을 따른 단순 정렬이 1번을 고른 이유를 확인한다. 수동 화살표를 물리적 정답으로 승인할 필요는 없다. 실제 주로 기준이 부족하면 미확인으로 유지한다.
