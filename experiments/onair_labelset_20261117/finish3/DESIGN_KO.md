# finish3 — v10을 통째로 새 날에서 시험 (1단계 설계)

2026-11-19 밤. 사용자가 자는 동안 할 일을 물었고("밤에 계속 연구하거나 테스트해볼만하게 있어?"), 계획을 알린 뒤 시작했다. 이 문서와 실행·채점 코드를 **새 날의 식별기 출력을 한 번도 만들기 전에** 잠근다(`DESIGN_LOCK.sha256`). 뒤에 바뀐 것은 `EVENTS.jsonl`에 적는다.

## 무엇을 시험하는가

**v10 = v9 + 결승 36초 전부터는 공식 기록으로 배운 선두 모델 + 결승 직전 6초의 화면 31장으로 우승마 부르기.**

두 조각은 `finish2/`에서 따로따로 확인했다(확인용 3일: 선두 66.0% → 88.6%, 우승마 19개 경주 중 14개를 부르고 14개 맞음). **묶은 것을 경주 처음부터 끝까지 돌려서 잰 적은 없다.** 2026-11-19에 식별기 프로그램에 `--v10`으로 넣었고(`identifier/identify_l1.py`), 이 시험은 프로그램이 쓰는 것과 같은 클래스(`LeadingGroupIdentifier(finish_leader=True)`)를 쓴다.

## 새 날

**2026-08-29, 2026-08-23** (`otherday12`, `otherday13`, 서울, 각 10개 경주). v9의 띠 구간 확인(`night/confirm2/`)에 쓴 날이다.

- 이미 본 것: 띠가 화면에 있는 구간에서 v9의 A, B, 선두, 앞뒤(2026-11-18 저녁).
- **본 적 없는 것: 이 2일의 공식 기록, 띠 없는 구간(출발 직후, 마지막 30초), 결승 순간, 우승마.** 공식 성적표는 이 문서를 잠근 뒤에 받는다.
- v10의 조각을 고르고 선두 모델을 학습하는 데는 쓰지 않았다(학습은 개발용 6일).

완전히 처음 보는 날은 아니다. 띠 구간에서 v9가 잘 됐다는 것은 알고 있으므로, 중반 구간의 결과는 놀랍지 않을 것이다. 이 시험이 새로 알려 주는 것은 **결승 구간과 우승마, 그리고 경주 전체의 선두**다.

## 실행

`code/g1_official_days.py`(공식 성적표, `fn1_official.py`의 해석기 그대로) → `code/fn2_times.py`(화면 시계) → `code/g2_whole_v10.py DAY`.

- 시점: `finish2`의 경주 전체 측정(`fn10_whole.py`)과 같다. 우승마의 결승 시각과 그 앞 3초마다, 출발 9초 뒤까지. 영상 시각과 경주 시각은 화면 시계와 공식 우승 기록으로 맞춘다(`fn_common.video_finish`).
- 결승 36초 전부터의 시점에서만 새 선두 모델을 쓴다. 같은 시점에서 띠로 배운 모델(v9)의 선두도 함께 남겨 **같은 시점에서 v9와 견준다.**
- 우승마는 두 가지로 부른다: 결승 시각을 공식 기록으로 잡은 것(`finish2` 실험과 같은 방식), 화면 시계가 멈춘 시각만으로 잡은 것(프로그램이 실제로 하는 방식).
- 식별기는 띠, 공식 기록, 소리를 읽지 않는다. 공식 기록은 시점을 놓는 데와 채점에만 쓴다.

## 채점 (`code/g3_score.py`)

정답은 공식 통과 시각으로 계산한 그 순간의 순서(`fn_common.reference_full`, 엄격 기준. 3m 이내를 인정하는 느슨한 기준은 함께 적는다). 주 분석은 화면 시계가 공식 기록과 맞는 경주. 구간은 경주 단위 다시 뽑기 2000번(씨앗 20261118).

| 지표 | 뜻 |
|---|---|
| A, B | 말한 번호 중 상위 3두인 비율, 맞는 번호가 하나 이상 있는 시점의 비율 |
| 선두 (말했을 때) | 선두라고 한 번호가 실제 1위인 비율 |
| 선두를 맞게 말한 시점 | 전체 시점 가운데 (2026-11-18에 벤치마크에 넣은 대표 지표와 같은 뜻) |
| 선두를 틀리게 말한 시점 | 전체 시점 가운데 |
| 우승마 | 부른 경주 수, 그중 공식 1위와 같은 수 |

구간: 출발(경주 시각 18초 전), 중반, 결승(마지막 36초), 경주 전체, 결승 순간을 뺀 경주 전체.

## 미리 정한 판정 (2일 합계, 주 분석)

| 판정 | 조건 |
|---|---|
| P1 번호는 경주 전체에서 목표를 채운다 | 경주 전체 A 90% 이상, B 80% 이상 |
| P2 결승 구간의 선두가 된다 | 결승 구간에서 선두(말했을 때) 80% 이상이고, 같은 시점의 v9 선두보다 높으며 차이의 95% 구간 아래 끝이 0보다 크다 |
| P3 경주 전체에서 선두를 더 맞게 말한다 | "선두를 맞게 말한 시점" v10 − v9 차이의 구간 아래 끝이 0보다 크고, "틀리게 말한 시점"이 v9보다 2%p 넘게 높지 않다 |
| P4 우승마를 부를 수 있다 (공식 기록으로 잡은 결승) | 경주의 절반 이상에서 부르고, 부른 것의 90% 이상이 맞다 |
| P5 우승마를 부를 수 있다 (화면 시계만) | P4와 같은 기준. 프로그램이 실제로 쓰는 방식 |
| **v10이 묶은 상태로 통한다** | P1, P2, P4가 모두 참 |

앞선 값(참고): v9의 경주 전체는 6일 43개 경주에서 A 92.6%, B 89.9%, 결승 구간의 선두는 66.1%였다. 새 선두 모델은 확인용 3일에서 88.6%, 우승마는 14/19를 부르고 14개가 맞았다.
