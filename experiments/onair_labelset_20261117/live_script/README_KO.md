# 중계 스크립트 시연 (live_script)

2026-11-18. 한 번도 쓰지 않은 경주 영상 하나로, 띠 없이 화면만 보고 중계 스크립트를 처음부터 끝까지 만들어 본 것이다. 미리 고정한 시험이 아니라 시연이다.

- **경주:** 2026-11-08 서울 11경주, 1400m, 8두. "쓰지 않은 가장 최근 경마일의 마지막 경주"로 내용을 보기 전에 정했다. 영상은 소리와 함께 받았고(서버에만 있음), 소리는 시스템에 넣지 않았다.
- **흐름:** 식별기 v9가 3초마다 선두권 번호와 선두를 냄 → 결승 36초쯤 전부터는 공식 기록으로 배운 선두 모델, 결승 순간에는 마지막 6초 그림으로 우승마 부르기(v10의 조각) → 코드가 "말해도 되는 사실"만 넘김 → 로컬 언어 모델(qwen3.8 27B, 글만 봄)이 캐스터 말투로 씀 → 코드의 규칙 검사와 같은 모델의 사실 검수를 통과하지 못하면 다시 시키고, 네 번 안에 안 되면 정해진 틀의 문장을 씀.
- **결과(공식 기록으로 나중에 확인):** 29문장 가운데 말을 부른 문장 24개. 부른 번호 33개 중 32개가 그 순간 실제 1~3위(나머지 1개는 3위와 3m 안), "선두" 주장 11개 모두 맞음, 우승마(8번) 맞음. 문장 22개는 모델이, 7개는 틀이 썼다. 문장 하나에 1.2초쯤.
- **읽어 보면:** 틀리지는 않지만 실제 중계보다 밋밋하다. 모델은 "바짝 추격", "접전", "독주" 같은 말을 자꾸 쓰려 했고, 거리 차이는 식별기가 알려 주지 않는 것이라 걸러 냈다. 규칙 검사만으로는 뜻이 뒤집힌 문장("선두가 다른 말을 앞에 두고 달린다")이 통과한 적이 있어 사실 검수 단계를 더했다.
- **한계:** 경주 하나다. 말 사이의 거리, 코너와 직선주로, 뒤쪽 말, 기수는 말하지 못한다. 남은 거리는 어림값이다. 실시간으로 돌린 것이 아니고 소리로 읽어 주지 않는다. 결승 36초 전이라는 시점은 경주 거리로 어림했다.
