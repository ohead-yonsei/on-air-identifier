# caps3 — 라벨 수집 한 번 더, 그리고 순서 모델을 새 분류기에 맞춰 다시 학습 (설계)

2026-11-19 오후. 사용자가 두 가지를 해 보라고 했다("네 해주세요"): 새 분류기로 같은 방식의 라벨 수집을 한 번 더 돌리는 것, 앞선 말 고르기·선두 모델을 새 분류기에 맞춰 다시 학습하는 것. 이미 본 날들에서 후보를 고른 뒤, 이 문서와 코드와 모델을 **새 날의 영상을 받기 전에** 잠근다(`DESIGN_LOCK.sha256`).

## 만든 것

| 이름 | 내용 |
|---|---|
| 분류기 B (`cnn/models/caps2_b.pt`) | v11의 분류기(A)를 기준으로 라벨을 한 번 더 모았다: 공식 기록 279장 + 띠 57장 = 336장. 첫 번째의 545장과 합쳐(겹치는 것 제외) 863장 + 직접 붙인 598장으로 학습. 설정은 A와 같다 |
| 모델 묶음 M (`caps2/models/*_A.joblib`, `*_B.joblib`) | 앞선 말 고르기 모델, 선두 모델, 결승 구간 선두 모델을 같은 날·같은 정답·같은 설정으로 다시 학습하되, 번호 확률만 새 분류기(A 또는 B)의 것으로 바꿨다(`code/h7_train_models.py`) |

두 번째 라벨은 첫 번째보다 잡음이 많다. Claude가 50장을 눈으로 봤는데, 10번·11번 이상은 대체로 맞았고, 분류기가 다른 번호를 강하게 확신한 그림은 열에 서너 장이 틀려 보였다(헬멧이 초록·검정·보라인데 1번이라고 붙은 것). 손실의 잡음 가정(10%)은 바꾸지 않았다.

## 고르는 단계 (이미 본 7일, 결론 아님)

라벨과 모델 학습에 쓰지 않은 7일(9월 12일, 5일, 8월 30일, 22일, 16일, 15일, 9일), 시계가 맞는 52개 경주, 1,378개 시점. 같은 기수 상자에서 v11과 견줬다(`code/h8_eval_combo.py`, `eval_held.txt`). 규칙은 돌리기 전에 스크립트에 적었다: 해치지 않는 후보(틀린 선두 +1.0%p 이내, A·B −1.0%p 이내) 가운데 선두를 맞게 말한 시점이 가장 높은 것.

| | 선두 번호 확정 | 선두를 맞게 / 틀리게 | A / B | v11과의 차이 (95% 구간) |
|---|---|---|---|---|
| v11 (분류기 A + 지금 모델) | 75.8% | 48.1% / 7.1% | 93.4% / 91.8% | — |
| **B** (분류기 B + 지금 모델) | 78.5% | 49.9% / 7.0% | 93.9% / 93.6% | 선두 맞게 −0.4 ~ +3.9, B +0.4 ~ +3.3 |
| A+M (분류기 A + 다시 학습한 모델) | 75.8% | 51.6% / 8.3% | 93.6% / 91.1% | 선두 맞게 +2.0 ~ +5.1, 틀리게 0.0 ~ +2.3, B −1.4 ~ −0.1 |
| B+M (분류기 B + 다시 학습한 모델) | 78.5% | 54.3% / 8.6% | 94.0% / 94.0% | 선두 맞게 +3.2 ~ +8.9, 틀리게 +0.2 ~ +2.9, B +0.5 ~ +3.9 |

- 규칙으로 고른 것은 **B**다. A+M과 B+M은 틀린 선두가 1.0%p 넘게 늘어(+1.2, +1.5) 규칙에서 빠졌다.
- 다만 B+M은 선두를 맞게 말한 시점이 6.2%p 늘고 틀리게 말한 시점이 1.5%p 느는, 지금까지 본 것 중 가장 좋은 맞바꿈 비율이다. 규칙으로 고른 것은 아니지만 **둘째 후보로 함께 확인한다**(판정을 따로 둔다).

## 실행과 채점

`run_test.sh`: 영상 받기 → 공식 성적표와 화면 시계 → 화면 처리(`g4_dense_whole.py`, `g10_dense_last.py`) → 같은 기수 상자에 분류기 A와 B의 확률 계산(`h4_reprob.py`) → `h8_eval_combo.py` 한 번 → `h9_verdict.py`.

정답은 공식 통과 시각으로 계산한 순서, 주 분석은 화면 시계가 공식 기록과 맞는 경주, 구간은 경주 단위 다시 뽑기 2000번(씨앗 20261118). 비교 대상은 v11이다.

## 미리 정한 판정 (2일 합계)

| 판정 | 조건 |
|---|---|
| **B가 v11보다 낫다** (첫째 후보) | 해치지 않는다(틀린 선두 +1.0%p 이내, A와 B가 −1.0%p 이내) 그리고 "선두를 맞게 말한 시점" 또는 번호 문장 B의 차이에서 95% 구간 아래 끝이 0보다 크다 |
| **B+M이 선두를 더 자주 맞게 말한다** (둘째 후보) | "선두를 맞게 말한 시점" 차이의 구간 아래 끝이 0보다 크고, 틀린 선두가 2.0%p 넘게 늘지 않고, A와 B가 1.0%p 넘게 줄지 않는다 |

우승마 부르기는 판정 없이 나란히 적는다. **기본값은 이 시험으로 바꾸지 않는다.** 결과를 사용자에게 알리고 정한다.
