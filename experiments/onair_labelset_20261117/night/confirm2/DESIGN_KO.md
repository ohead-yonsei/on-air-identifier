# 후보 구성 F2 확인 — 설계

2026-11-18 새벽. 밤 실험([../RESULT_KO.md](../RESULT_KO.md))에서 따로따로 확인된 세 가지를 하나로 묶은 구성을, 한 번도 쓰지 않은 날에서 확인하려는 설계다. 새 날의 결과를 보기 전에 이 문서와 채점 코드를 잠갔다(`DESIGN_LOCK.sha256`).

## 무엇을 확인하는가

**F2 = Qwen 없는 빠른 구성(F1) + 빈 시점 메우기 + 선두 기준값 0.5**

| 조각 | 밤 실험(새 날 나흘)에서 확인된 것 |
|---|---|
| Qwen 빼기 (F1) | L1보다 나쁘지 않았다 (A 94.3% / B 87.6% 대 95.1% / 86.2%) |
| 빈 시점 메우기 | L1 위에서 B가 86.2% → 91.0%, A는 0.5%p 내려갔다 |
| 선두 기준값 0.5 | L1 위에서 87.5%, 하루씩 모두 80% 이상. 기준값 0.6은 하루(9/5)가 79.0%였다 |

세 조각을 **함께** 쓴 것은 미리 정한 시험으로 잰 적이 없다. 같은 나흘에서 묶어 계산한 값(`explore_seen_days.json`, 이미 본 날이라 탐색)은 A 93.9% (1011개 중 949개), B 90.7% (579개 중 525개), 선두 88.1% (353번 중 311번), 앞뒤 91.8% (355번 중 326번)였다.

## 채점과 미리 정한 판정

`code/nc2_score.py`. 기준은 순위 띠, 띠가 화면에 있는 시점만. 구간은 경주 단위 다시 뽑기 2000번(씨앗 20261118).

| 판정 | 조건 |
|---|---|
| F2가 목표를 채운다 | 이틀 합쳐 A 90% 이상, B 80% 이상. 하루씩도 둘 다 |
| F2가 지금 구성(L1)보다 나쁘지 않다 | 합친 A가 L1보다 2%p 넘게 낮지 않고, B가 3%p 넘게 낮지 않다 |
| 빠른 구성에서도 메우기가 도움이 된다 | F2와 F1의 B 차이 95% 구간 아래 끝이 0보다 크고, A가 F1보다 1%p 넘게 낮지 않고 90% 이상 |
| 선두를 말할 수 있다 (빠른 선두 모델, 0.5) | 합쳐서 85% 이상, 하루씩 80% 이상 |
| 앞뒤를 말할 수 있다 (F2의 문장 위에서, 0.2) | 합쳐서 90% 이상, 하루씩 85% 이상 |
| **F2를 기본 구성으로 권한다** | 첫째, 둘째, 넷째, 다섯째가 모두 참 (첫째는 하루씩도) |

셋째는 메우기의 몫을 따로 적는 것이다. 이틀(20개 경주)로는 구간이 넓어 0을 걸칠 수 있다.

프로그램 확인: `identify_l1.py --fast --fallback --leader-tau 0.5`가 채점 스크립트의 F2와 같은 문장을 내는지 본다(`code/nc4_check_f2.py`).
