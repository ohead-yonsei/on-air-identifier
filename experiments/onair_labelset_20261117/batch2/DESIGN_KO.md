# 2차 묶음 재시험 — 설계 (새 프레임을 뽑기 전에 고정)

작성: 2026-11-17. 이 문서와 채점 코드(`code/b2_classify.py`, `code/b2_evaluate.py`)는 2차 프레임을 추출하기 전에 쓰고 해시를 남긴다.

## 목적

1차 묶음(147명)에서 결과를 본 뒤 떠올린 "Qwen + 학습한 분류기 + 화면 안 배정" 방식이, 본 적 없는 새 프레임에서도 Qwen 단독보다 나은지 확인한다. 1차에서는 85명 → 103명이었지만 사후 탐색이었다.

## 데이터

- 같은 10개 경주(2026-09-06 서울)에서 새 프레임을 경주당 5장 뽑는다. 경주 구간 안에서 고르게 나누되, Codex가 쓴 프레임과 1차 묶음 프레임에서 3초 이상 떨어지게 한다.
- 기수 상자 규칙은 1차와 같다(사람 검출 점수 0.5 이상, 높이 70픽셀 이상, 말 상자와 겹침, 화면 가장자리·그래픽 제외).
- 번호 초안은 Claude가 기수 사진을 보고 적고, 사용자가 검수한다. **검수가 끝나 라벨 해시를 고정하기 전에는 어떤 분류기도 2차 프레임에 돌리지 않는다.** 초안이 모델 출력에 끌려가지 않게 하기 위해서다.
- 채점 대상은 사람 번호(1~11번)가 있고 중복 상자가 아닌 기수다.

## 고정한 방법

1차 묶음과 똑같다. 2차 데이터를 보고 바꾸는 값은 없다.

- 모자 영역: R0_27(상단 27%, 좌우 8% 제외), R0_35(상단 35%).
- Qwen 9B: R0_35 영역, `cap_classifier.json` 프로토콜과 생성 설정 그대로.
- 학습한 분류기: R0_27 영역의 색 특징 21개, 표준화 후 `LogisticRegression(C=1.0, max_iter=2000)`. **학습 데이터는 1차 묶음의 147명뿐이다.**
- 합친 점수: 학습한 분류기의 확률 + (Qwen이 고른 번호에 1.0).
- 배정: 같은 화면의 채점 대상 기수 전부에 서로 다른 번호를 점수 합이 최대가 되게 배정(헝가리안, 후보 1~11번).

## 조건

| 이름 | 내용 |
|---|---|
| Q | Qwen 단독 |
| H | 색 규칙(식별기 v4, R0_27) |
| L_I, L_A | 학습한 분류기 단독 / 배정 |
| C_I, C_A | 합친 점수 단독 / 배정 |

학습 데이터를 두 가지로 쓴다.

- **경주 제외(주 결과)**: 시험하는 기수의 경주를 뺀 1차 묶음 9개 경주로 학습. 프레임도 경주도 처음 보는 조건이다.
- 전체: 1차 묶음 147명 전부로 학습. 같은 경주의 다른 프레임을 본 조건이다.

## 주 비교와 판정 기준

- **주 비교는 Q 대 C_A(경주 제외 학습)** 다. 같은 기수끼리 짝지어 좋아진 수와 나빠진 수를 센다.
- "재현됐다"고 말하는 기준: 좋아진 수가 나빠진 수보다 많고 부호 검정 p < 0.05.
- 기준에 못 미치면 "재현되지 않았다"고 쓴다. 기준을 결과에 맞춰 바꾸지 않는다.
- 함께 보고할 것: 조건별 정답 / 오답 / 보류, 번호별 정답 수, 경주별 정답 수, 오답 수의 변화(C_A는 보류가 없으므로 오답이 늘 수 있다).

## 미리 적어 두는 한계

- 2차 프레임은 1차와 같은 날, 같은 경주에서 몇 초 떨어진 화면이다. 같은 기수·같은 경주복·비슷한 조명이 다시 나온다. "경주 제외" 조건이 이 점을 일부 막아 주지만, 다른 날짜로의 일반화 시험은 아니다.
- 초안을 적는 Claude는 1차 결과(어떤 색이 헷갈리는지)를 알고 있다. 사용자 검수가 최종 기준이다.
