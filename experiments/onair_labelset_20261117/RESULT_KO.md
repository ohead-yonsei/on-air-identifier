## 결론

1. **지금 방식으로는 기수 전원 기준 절반 안팎만 맞는다.** 색 규칙(식별기 v4)은 147명 중 61명, Qwen 9B는 85명을 맞혔다. Qwen은 답을 낸 113명 중 85명이 정답이고 34명은 보류했다.
2. **Qwen의 실패는 네 가지 색에 몰려 있다.** 검정·갈색·하늘색·줄무늬(4·7·10·11번) 42명 중 1명만 맞혔다. 나머지 일곱 색은 105명 중 84명을 맞혔다. 하늘색은 11명 중 10명을 "파랑"이라고 답했고, 검정·갈색·줄무늬는 대부분 보류했다.
3. **이 중계 화면의 라벨로 학습하면 색 규칙보다 낫다.** 처음 보는 경주에서 64명 → 85명(좋아짐 36, 나빠짐 15). 갈색은 0 → 7명, 하늘색은 0 → 4명을 맞히기 시작했다. 줄무늬는 여전히 0명이다.
4. **출전마 전체에 번호를 겹치지 않게 배정하면 색 규칙이 뚜렷하게 좋아진다.** 64 → 78명(좋아짐 21, 나빠짐 7). 아침에 화면당 3명으로 시험했을 때 효과가 거의 없었던 것은 기수가 적어서였다.

## 사후 탐색 (결과를 본 뒤 추가한 것, 결론이 아님)

위 결과에서 Qwen과 학습한 분류기가 서로 다른 색에 강하다는 것을 보고, 둘을 합쳐 봤다.

- 점수 = 학습한 분류기의 확률 + (Qwen이 고른 번호에 1점). 가중치 1은 조정하지 않았다.
- 그 점수로 화면 안에서 번호가 겹치지 않게 배정했다.

| 조건 | 정답 / 오답 / 보류 |
|---|---|
| Qwen 9B 단독 | 85 / 28 / 34 |
| 합친 점수, 배정 없이 | 95 / 52 / 0 |
| 합친 점수 + 배정 | 103 / 44 / 0 |

Qwen 단독 대비 좋아짐 20, 나빠짐 2다. 번호별로는 갈색 0 → 7, 검정 0 → 3, 하늘색 0 → 3이 늘었고, 다른 색은 거의 그대로다.

**이 숫자는 같은 147명을 보고 떠올린 방법을 같은 147명으로 잰 것이다.** 새 프레임으로 다시 시험하기 전에는 "103명"을 성능으로 말할 수 없다. 다음 시험의 후보로만 적어 둔다.

합친 뒤에도 남는 오답: 하늘색 10번과 줄무늬 11번이 서로 바뀐다(10 → 11이 4명, 11 → 10이 5명). 갈색 15명 중 3명은 검정으로 간다.
