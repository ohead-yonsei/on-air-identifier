# live1: 영상을 실제 속도로 읽으며 자막 내기 — 시연 결과 (2026-11-22)

미리 고정한 시험이 아니라 시연이다. 경주 하나(2026-11-08 서울 11경주, 1400m, 8두)이고, 이 경주는 2026-11-18의 스크립트 시연에 이미 쓴 것이다(식별기의 학습과 선택에는 쓰지 않았다).

## 무엇을 돌렸나

`identifier/live_run.py`. 영상을 한 장씩 차례로 읽되, 영상 시각 v의 화면은 실제 시각으로 v초가 지나기 전에는 건드리지 않는다. 그래서 모든 판단은 이미 지나간 화면만 쓴다.

1. 화면의 경주 시계가 돌기 시작하면 출발로 본다(1초 뒤에 알아차림). 출발 문장을 낸다.
2. 출발 9초 뒤부터 3초마다 식별기 v11(지금, 0.5초 전, 1초 전 그림)을 돌리고, 정해진 문장 틀로 문장을 낸다. 언어 모델은 쓰지 않는다.
3. 결승이 가까워지면(거리로 어림한 결승 14초 전부터) 0.2초마다 그림을 미리 돌려 둔다. 밀려 있으면 이 그림부터 건너뛴다.
4. 시계가 멈추면(1초 뒤에 알아차림) 미리 돌려 둔 그림으로 우승마를 부른다(`--winner-call`과 같은 규칙).

문장이 준비된 실제 시각을 적어 두고, 그 시각에 자막이 뜨는 영상을 만든다. 띠, 공식 결과, 방송 소리, 남은 거리 표시는 읽지 않는다. 순위 변화 문장("올라왔다", "제쳤다")은 내지 않는다.

## 읽을 때 조심할 것

- **경주 하나다.** 지연은 RTX 3090 한 대에서 다른 작업 없이 잰 값이다.
- 방송을 받는 데 걸리는 시간, 자막을 화면에 올리는 시간, 소리로 읽어 주는 시간은 들어 있지 않다. 파일을 실제 속도로 읽은 것이고 실제 생방송에 붙인 것이 아니다.
- 문장이 단조롭다. 상태가 같으면 "계속 선두입니다", "여전히 선두는"을 번갈아 낸다. 문장을 다채롭게 만드는 일(표현은행)은 이 스크립트의 범위가 아니다.
- 말 이름은 출전표에서 가져왔다(번호 → 이름). 11번 이상 모자는 구분되지 않아, 출전표에 11번 이상이 한 마리일 때만 부른다.
- 선두 3개가 틀린 것은 식별기 v11의 한계다(결승 직선의 먼 화면에서 선두를 늦게 바꿈). 결승 구간용 선두 모델(v10의 조각)은 이 스크립트에 넣지 않았다.
